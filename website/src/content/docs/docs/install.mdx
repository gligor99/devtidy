export const install = (url, dir) =>
  `curl -L ${url} | tar xz\nsudo mv ${dir}/devtidy /usr/local/bin/\ndevtidy --version`

The latest release is **v{VERSION}**. All files are on
[GitHub Releases](https://github.com/gligor99/devtidy/releases/latest), with a
`SHA256SUMS` file to verify them.

## Desktop app (macOS)

Requires macOS 12 or later. One universal build runs natively on Apple
Silicon and Intel.

<Steps>

1. Download <a href={DOWNLOADS.dmg}>DevTidy_{VERSION}_universal.dmg</a>.
2. Open it and drag **DevTidy** into **Applications**.
3. The first time, right-click DevTidy in Applications and choose **Open**,
   then **Open** again in the dialog.

</Steps>

<Aside type="note" title="Why the extra step?">
DevTidy is not notarized by Apple yet, so macOS asks before opening an app
from an unidentified developer. It is only needed once. You can also clear the
quarantine flag from a terminal:

```sh
xattr -dr com.apple.quarantine /Applications/DevTidy.app
```

Notarized builds will come with v1.0.
</Aside>

## Verify a download

```sh
shasum -a 256 -c SHA256SUMS --ignore-missing
```

## Uninstall

Delete `DevTidy.app` and `/usr/local/bin/devtidy`. DevTidy keeps its scan
history in `~/Library/Application Support/devtidy/`; delete that folder to
remove every trace.
